
I will use CLI for this task.

First we generate DH parameters that will be shared between Bob and Alice:
openssl dhparam -out dhparams.pem 2048

Then we generate private keys for Bob and Alice:
openssl genpkey -paramfile dhparams.pem -out alice_private.pem
openssl genpkey -paramfile dhparams.pem -out bob_private.pem

The files have been generated in the directory.
Nex we extract the public keys:
openssl pkey -in alice_private.pem -pubout -out alice_public.pem
openssl pkey -in bob_private.pem -pubout -out bob_public.pem

Deriving the shared secret key with CLI was a bit tricky but I managed to do it using the openssl pkeyutl command:
For Bob:
openssl pkeyutl -derive -inkey bob_private.pem -peerkey alice_public.pem -out bob_secret.bin

For Alice:
openssl pkeyutl -derive -inkey alice_private.pem -peerkey bob_public.pem -out alice_secret.bin
